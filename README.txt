# WEIR Weather App

## Setup Instructions

1. Replace `'YOUR_OPENWEATHERMAP_API_KEY'` in `script.js` with your real OpenWeatherMap API key.
2. Open `index.html` in a browser to preview locally.
3. Push to GitHub:
   - Open GitHub Desktop
   - Clone your `WeirWeatherDisplay` repository
   - Replace its contents with the files from this ZIP
   - Commit and push changes

## Optional Hosting

To publish online, use GitHub Pages or Netlify for static hosting.
